HMAC (keyed hash)

With a key, the table above shows HMAC-MD5 / HMAC-SHA-* of the same message instead (CRC-32 has no HMAC).
MD5 and SHA-1 are fine as integrity checksums against accidental corruption, but both are cryptographically broken: collisions can be manufactured, so don't use them for signatures or fingerprinting attacker-supplied data. CRC-32 is only an error-detection code — it is trivially forgeable and not a cryptographic hash at all. Files are hashed in memory in your browser; very large files (hundreds of MB) may be slow or fail, but they still never leave your machine.
