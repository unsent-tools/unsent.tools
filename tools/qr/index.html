Any text or URL as a QR code — versions 1–40, all four error-correction levels, mask chosen by the standard's penalty rules, downloadable as crisp SVG or PNG. Generated entirely in your browser: nothing you type leaves this page.

Higher error correction survives more damage (or a logo pasted over the middle) but makes a denser code. Keep dark-on-light: scanners assume it.

Check it before you print it. This generator is tested against independent implementations (see how these are tested), but a scan with your own phone is the test that matters — especially after changing colors. Low contrast is the usual culprit.

Content is encoded in the cheapest mode that fits: digits only → numeric, the 45-character uppercase set → alphanumeric, anything else → bytes as UTF-8. That's why EXAMPLE.ORG makes a sparser code than example.org.
