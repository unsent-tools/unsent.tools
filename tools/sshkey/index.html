SSH key decoder

Paste SSH public keys — bare lines, authorized_keys with options, known_hosts (hashed or not), RFC 4716 blocks, OpenSSH certificates — and get the type, size, SHA256 and MD5 fingerprints, randomart, and every certificate field, exactly as ssh-keygen would report them. Nothing you paste leaves this page.
